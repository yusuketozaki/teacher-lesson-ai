# 公開・情報管理

## 公開してよい情報

- 一般化した機能要件と設計判断
- 架空の例、合成データ、権利確認済みの資料
- 秘密情報を含まない再現手順と検証結果

## 公開しない情報

- 児童生徒の氏名、成績、健康・行動記録、自由記述から再特定できる出来事
- 教員への私的なインタビュー原文、学校内部の資料や未承認の実画面
- API キー、トークン、パスワード、個人メール、私的な環境の絶対パス

この境界はソースだけでなく Issue、PR、添付画像、CI ログ、AI エージェントに渡す入力にも適用します。公開 Issue に機密性のある脆弱性や漏えいデータを再投稿しないでください。

## OSS と権利

public は閲覧可能であることを示すだけで、包括的な再利用許諾ではありません。現時点ではライセンスを付与していません。ライセンス追加・外部コード利用の前に、権利者、所属先等との権利関係、依存ライセンスを確認します。

## 将来の AI 連携の前提

データ送信先・保存期間・学習利用・削除・契約条件・費用上限・ログ方針を設計し、利用組織のルールを確認します。秘密情報はサーバー側で保持し、クライアント用環境変数に含めません。これらの確認が完了したと実装や文書だけから断定しません。
