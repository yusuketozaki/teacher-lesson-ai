# 安全設計チェックリスト

これは設計上の課題一覧であり、法令適合や学校での利用許可を保証するものではありません。

- [ ] 利用する学校・教育委員会のルール、利用主体と契約主体を確認する。
- [ ] 児童生徒情報を必要としない入力項目に限定する。自由記述でも特定につながる情報がありうる。
- [ ] 教材や参考資料の権利と利用条件を確認する。教科書の自由なアップロードを前提にしない。
- [ ] AI 接続前にデータ送信先、保存期間、学習利用、削除、契約条件を定める。
- [ ] 生成結果を教員が確認・修正し、教育課程との整合性と事実性を検証できるようにする。
- [ ] 外部通信・ログ・アクセス制御・費用上限を設計し、試験する。

現在の実装には入力フォーム、外部 AI 接続、データベースはありません。設定値のテストはスコープの確認であり、漏えい防止機構の検証ではありません。
